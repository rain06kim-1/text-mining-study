# ✅ 정답 & 해설  (먼저 풀고 내려오기!)

### A.
- **A1.** 전처리(preprocessing)
- **A2.** 토큰화(tokenization) / `.split()`
- **A3.** 불용어(stopword)
- **A4.** `Counter` / `.most_common(5)`
- **A5.** 한글·특수문자 같은 글자가 **깨지지 않게** 하려고. (파일을 어떤 글자 규칙으로 읽을지 알려주는 약속)
- **A6.** `lyrics` 폴더 안 **파일 이름들의 리스트** (예: `['HOPE - NF.txt', 'The Search - NF.txt', 'Time - NF.txt']`). 폴더 이름은 안 붙어 있음에 주의!
- **A7.** `FileNotFoundError`

### B.
- **B1.** `['never', 'give', 'up', 'never']`
  - `.lower()` 로 전부 소문자 → 쉼표 제거 → `.split()` 로 단어 리스트.
- **B2.** `[('time', 3), ('my', 2)]`
  - `time` 3번, `my` 2번이 가장 많음. `(단어, 횟수)` 튜플로 나옴.
- **B3.** `['time', 'my', 'need']`
  - 각 튜플의 `pair[0]`(=단어)만 뽑은 것.

### C.
- **C1.** `analyze_lyrics(text)` 가 `for` **바깥**에 있어서, 반복문은 파일만 3번 읽어 `text` 를 덮어쓰고, 분석은 **맨 마지막 곡 1번만** 실행됨. → `analyze_lyrics(text)` 를 `for` **안쪽으로 들여쓰기** 하면 곡마다 실행됨.
- **C2.** 경로에 폴더가 빠짐. `'Time - NF.txt'` → `'lyrics/Time - NF.txt'` 로 고쳐야 함. (파일이 `lyrics` 폴더 안에 있으므로)
- **C3.** `filename` 은 함수가 **받은 재료가 아니라 바깥(`for` 문)에 있는 변수**다. 지금은 우연히 그 변수가 존재해서 됐지만, 함수를 다른 곳에서 부르면 `filename` 이 없어 **에러**가 난다. → 함수는 받은 매개변수만 써야 독립적이고 안전: `plt.title(title)` 로 고친다.
